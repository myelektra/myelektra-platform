# ADR-003-Astro-Primary-Framework: Astro Primary Framework

Status: Accepted

## Context

See PRD-001 and Software Architecture documentation.

## Decision

Use Astro as the primary framework and React only for interactive islands.

## Consequences

### Positive

- Improves maintainability
- Supports long-term platform growth
- Reduces migration risk

### Trade-offs

- Requires discipline to follow repository standards
- Additional documentation must be maintained
